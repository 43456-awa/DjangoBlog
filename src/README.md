# src · 源代码目录

## 说明

本项目为**基于开源项目 DjangoBlog 的二次开发**，源代码沿用其原有目录结构（位于仓库根目录），
**未做物理迁移**。

不迁移的原因：Django 项目的布局与相对路径强耦合——`manage.py`、`settings.py` 中的 `BASE_DIR`、
各 app 间的 `import` 关系、前端构建产物输出路径等均以仓库根目录为基准。
强行将所有代码移入 `src/` 会导致项目无法启动，属于为形式牺牲可运行性的做法。

## 上游原有源代码（仓库根目录）

| 目录 | 职责 |
|---|---|
| `djangoblog/` | 项目配置：settings / urls / wsgi |
| `blog/` | 博客核心：文章、分类、标签、站点设置 |
| `accounts/` | 用户模型与认证 |
| `comments/` | 评论系统 |
| `oauth/` | 第三方登录 |
| `servermanager/` | 服务器信息管理 |
| `plugins/` | 插件系统 |
| `templates/` | 页面模板 |
| `frontend/` | 前端源码（Vite + Tailwind） |

## 本目录用途

存放小组**自主开发 / 二次开发**的代码模块。后续新增功能（例如站点扩展模块）
将置于本目录下，与上游代码保持清晰的边界，便于区分"哪些是我们写的"。

## 开发约定

- 新增模块以插件形式接入，不修改上游核心文件
- 每个模块自带 README，说明功能、依赖与接入方式
