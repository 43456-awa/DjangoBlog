# DjangoBlog 二次开发项目 · 项目说明

> 本文档为课程实践报告文档，存放于 `doc/` 目录。

## 一、项目来源

本项目基于开源博客系统 **DjangoBlog**（作者：liangliangyy）进行二次开发，
遵循 **GPL-3.0** 开源协议。

- 上游仓库：https://github.com/liangliangyy/DjangoBlog
- 本仓库：https://github.com/43456-awa/DjangoBlog

二次开发的目标是在保持原有博客功能完整的前提下，熟悉 Django 分层架构、
数据模型设计，并逐步扩展站点功能与界面。

## 二、技术栈

| 层次 | 技术选型 |
|---|---|
| 后端 | Python 3.11 + Django 5.2 |
| 数据库 | MySQL 8.0（字符集 utf8mb4） |
| 前端 | Tailwind CSS 3 + Vite 6 + Alpine.js + htmx |
| 全文检索 | Whoosh（Haystack 框架） |
| 缓存 | 本地内存缓存（LocMem），可选 Redis |
| 部署 | WSGI + 反向代理 + 进程守护（可选） |

## 三、目录结构

| 目录 | 职责 |
|---|---|
| `djangoblog/` | 项目配置：settings / urls / wsgi |
| `blog/` | 博客核心：文章、分类、标签、站点设置 |
| `accounts/` | 用户模型与认证 |
| `comments/` | 评论系统 |
| `oauth/` | 第三方登录 |
| `servermanager/` | 服务器信息管理 |
| `plugins/` | 插件系统（阅读时长、访问统计、SEO 等） |
| `templates/` | 页面模板 |
| `frontend/` | 前端源码（Vite + Tailwind，构建产物输出至 `blog/static/blog/dist/`） |
| `src/` | 小组自主开发代码（见 `src/README.md`） |
| `doc/` | 项目报告文档（本目录） |

## 四、开发环境

- 后端依赖：`pip install -r requirements.txt`
- 前端构建：`cd frontend && npm install && npm run build`
- 数据库连接信息通过**环境变量**注入，不写入仓库文件
- 启动：`python manage.py runserver`

## 六、开发规范

1. **框架不动、扩展随意**：不修改上游核心结构，新增功能以插件/新模块形式扩展
2. **小步提交**：每次提交聚焦单一改动，提交信息说明"改了什么、为什么改"
3. **分支管理**：`master` 保存稳定版本，个人开发在各自成员分支进行
4. **敏感信息**：数据库口令、密钥等一律通过环境变量注入，禁止提交到仓库
